Spatial transcriptomics of human glioblastoma

I used 10x Visium CytAssist data and Seurat to map transcriptional clusters onto a glioblastoma tissue section and explore where collagen and hypoxia gene programs are expressed.

Spatial findings

Where collagen and hypoxia scores are high

Collagen-gene expression was elevated in clusters 5 and 9. Areas with high hypoxia scores overlapped cluster 7. I mapped these clusters alongside the scores for five marker panels to see where the patterns coincided on the tissue.

Methods

From counts to tissue maps

The workflow runs in R with Seurat v5. It starts from processed Space Ranger counts and links each spot back to its location on the H&E image.

  1. Import and normalise. Load the filtered matrix and spatial files, inspect counts per spot and run SCTransform().
  2. Cluster and map spots. Use the first 30 principal components for graph-based clustering and UMAP. Overlay cluster labels on H&E.
  3. Rank spatially variable genes. Run Moran’s I on 1,000 highly variable genes and a mark variogram on 10.
  4. Compare clusters. Rank positive markers by log₂ fold change and compare mean SCT residual profiles using Spearman correlation.
  5. Score marker panels. Map collagen, hypoxia, MES1-associated, MES2-associated and GBM panels with AddModuleScore().

Reproducibility

Data and code

This exploratory analysis uses one formalin-fixed, paraffin-embedded human glioblastoma section profiled in an 11 mm Visium CytAssist capture area. Module scores summarise expression at the spot level.

The data were processed with Space Ranger 2.0.1 and released under CC BY 4.0. 10x Genomics dataset and downloads

How to rerun the notebook
  1. Use R with Seurat v5 and install the packages loaded in the R Markdown source.
  2. Download the filtered HDF5 matrix and spatial imaging archive from 10x Genomics. Save the matrix as data/filtered_feature_bc_matrix.h5 and extract the spatial files into data/spatial/.
  3. Place data/ beside the .Rmd file or set data_dir to its location. Run the notebook chunks in order.
